Court Calm
===========

Court Calm — це невеликий фронтенд-додаток, що допомагає підготуватися до матчу через короткі рутини та дихальні вправи. Проєкт побудований на Vite (ES Modules) і не має сервера — статичний сайт, який розгортається на GitHub Pages.

Ключові можливості
- Інтерфейс з кількома екранами: головна сторінка, підготовка, дихальні вправи, міжпоінтовий режим, пауза / reset.
- Підтримка двох мов: англійська (EN) та українська (UA). За замовчуванням встановлено англійську.
- Перемикач мови на головній панелі (кнопки UA / EN).
- Статична збірка через Vite у папку dist.

Швидкий старт (локально)
1. Клонувати репозиторій і перейти в папку проєкту:
   git clone https://github.com/Apex-developing/CourtCalm.git
   cd CourtCalm

2. Встановити залежності:
   npm install

3. Запустити dev-сервер:
   npm run dev

   Після цього відкрити у браузері URL, який виведе Vite (наприклад: http://localhost:1420).

Збірка для продакшна
- Згенерувати статичні файли в папку dist:
  npm run build

- Локально перевірити збірку з `npm run preview` або пересервісити dist на будь-якому статичному хостингу.

Деплой на GitHub Pages
У репозиторії з настроєним GitHub Actions є workflow `.github/workflows/deploy-pages.yml`, який:
- запускається при пуші в `main` або `master`,
- будує проєкт (`npm ci` + `npm run build`),
- завантажує артефакти з `./dist`,
- деплоїть сторінку в GitHub Pages.

Щоб оновити live-версію:
- Змерджити або запушити зміни у гілку `main` (або `master`) — workflow задеплоїть сайт автоматично.

Особливості реалізації i18n
- Тексти зберігаються у простому об'єкті `translations` у `src/main.js`.
- Поточна мова зберігається в `state.language` (значення: `"en"` або `"ua"`).
- UI має невеликий перемикач у верхній панелі (UA / EN). Мовні ресурси можна розширювати додаванням нових ключів у `translations`.

Файлова структура (коротко)
- src/
  - main.js       — головна логіка та рендеринг інтерфейсу
  - styles/       — CSS (index.css та overrides.css)
- public/         — статичні активи
- dist/           — збірка (генерується `npm run build`)
- .github/workflows/deploy-pages.yml — workflow для GitHub Pages
