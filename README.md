Court Calm
===========

Court Calm is a small frontend application that helps players prepare for a match using short routines and breathing exercises. The project is built with Vite (ES Modules) and is a static site with no backend — intended for deployment to GitHub Pages.

Key features
- Multiple screens: Home, Prepare, Breathing exercise, In-between points, and Reset/Pause.
- Language support: English (EN) and Ukrainian (UA). English is the default language.
- Simple language switch on the top bar (UA / EN buttons).
- Static build via Vite into the `dist/` folder.

Quick start (local)
1. Clone the repository and enter the project folder:
   git clone https://github.com/Apex-developing/CourtCalm.git
   cd CourtCalm

2. Install dependencies:
   npm install

3. Start the dev server:
   npm run dev

   Open the URL printed by Vite in your browser (for example: http://localhost:1420).

Production build
- Generate a production build into `dist/`:
  npm run build

- Optionally preview the production build locally:
  npm run preview

GitHub Pages deployment
The repository includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml` that:
- runs on push to `main` or `master`,
- installs dependencies and builds the project (`npm ci` + `npm run build`),
- uploads the `./dist` folder as an artifact, and
- deploys the site to GitHub Pages.

To update the live site:
- merge or push changes to the `main` (or `master`) branch — the workflow will deploy automatically.

i18n implementation notes
- Strings are stored in a simple `translations` object in `src/main.js`.
- Current language is kept in `state.language` (values: `"en"` or `"ua"`).
- Language switch is rendered in the top bar; translations can be extended by adding new keys to the `translations` object.

Project structure (short)
- src/
  - main.js       — main app logic and rendering
  - styles/       — CSS files (index.css and overrides.css)
- public/         — static assets
- dist/           — built output (generated by `npm run build`)
- .github/workflows/deploy-pages.yml — GitHub Actions workflow for Pages
